# Отчеты о багах — FitnessCourt (Bug Reports)

Этот файл служит единым источником правды для документирования найденных багов во время выполнения автоматизированного и ручного тестирования.

> [!IMPORTANT]
> Каждому багу должен быть присвоен уникальный идентификатор вида `[BUG-XX]`.
> Все скриншоты, дампы и логи ошибок должны быть зафиксированы в папке `artifacts/` и прилинкованы к отчету.

---

## Активные баги (Active Bugs)

*Здесь пока нет зарегистрированных багов. При нахождении нового бага задокументируйте его по шаблону ниже.*

---

## Шаблон отчета о баге (Bug Report Template)

### `[BUG-XX]` — [Краткое описание проблемы]

* **Приоритет**: Blocker / Critical / High / Medium / Low
* **Компонент**: Frontend / Backend / Telegram Bot / Database
* **Связаный тест**: `test_case_name` (ID: `AUTH-B01`)
* **Окружение**: Local / Dev / Staging
* **Артефакт**: ![Screenshot](../artifacts/screenshots/screenshot_bug_xx.png) / [Trace Log](../artifacts/traces/trace_bug_xx.zip)

#### Шаги для воспроизведения (Steps to Reproduce)
1. Открыть страницу...
2. Заполнить поле...
3. Нажать кнопку...

#### Фактический результат (Actual Result)
* Описание того, что произошло на самом деле (например, падение с ошибкой 500).

#### Ожидаемый результат (Expected Result)
* Описание правильного поведения системы.
