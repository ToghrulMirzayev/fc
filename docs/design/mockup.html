01 / Foundation Brand & system

Mark & wordmark

Gympass

An abstract chevron mark — a stylized peak, an upward arrow, a silhouette of momentum. Coral inner stroke nests inside a white outer one, suggesting compression and release. Independent of the working name, so the mark survives rebranding.

Direction

Midnight athletics. Dark base for operators who work eight-hour shifts. Editorial serif for tone — this is a tool, not a gadget. Coral as heartbeat, ozone as growth, ice for information. The green-and-white fitness cliché is deliberately avoided.

Principles

  • → Numbers are tabular and large
  • → Status is a colored pill, not an icon
  • → Receptionists never wait for a modal
  • → Every list view has a keyboard shortcut
  • → Tenant context is always visible
