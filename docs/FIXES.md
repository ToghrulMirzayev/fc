# Список доработок и фиксов (FIXES)

В данном документе зафиксирован перечень необходимых исправлений и нового функционала для веб-портала и Telegram-бота.

---

## 1. Веб-приложение (CRM & Панель управления)

### Авторизация и профиль пользователя (Auth & Profile)
- [ ] **Регистрация** — исправить/доработать форму регистрации пользователей (валидация полей, корректный вывод ошибок).
- [ ] **Восстановление пароля** — реализовать полноценный флоу сброса и восстановления пароля ("Забыли пароль?").
- [x] **Редактирование профиля** — добавить возможность редактирования личных данных пользователя непосредственно в личном кабинете (иконка "карандаш" у полей).

### Системные требования и локализация
- [ ] **Поддержка пробелов в названии зала** — исправить обработку названий фитнес-клубов (gyms), содержащих пробелы (корректная генерация слагов, URL и работа в API/БД).
- [ ] **Ролевая модель и подписка для сети** — реализовать систему доступов для различных ролей в рамках одной сети фитнес-клубов:
  - Владелец сети (Owner)
  - Администраторы (Admins)
  - Ресепшн / Регистраторы (Reception)
- [ ] **Локализация (L10n / I18n)** — внедрить поддержку нескольких языков интерфейса и локальное отображение цен (валюты) в зависимости от региона зала.

### Клиентская база (Members CRM)
- [x] **Автоматическое обновление статуса** — обеспечить мгновенное обновление статусов пользователей при внесении любых изменений (заморозка, продление, оплата) без необходимости ручной перезагрузки страниц.
- [x] **Skeleton / Loading UI** — внедрить скелетоны (скелетные экраны загрузки) или индикаторы загрузки (spinners) при обновлении списков и переключении разделов.
- [ ] **Дата рождения и рассылки** — добавить поле "Дата рождения" в карточку пользователя и связать его с рассылками/поздравлениями.
- [ ] **Архивация пользователей** — реализовать раздел "Архив пользователей" для деактивированных членов клуба с возможностью просмотра истории и восстановления.

## 2. Бэклог задач (Backlog)

- [ ] **Редактирование данных участников** — реализовать интерфейс для ручного изменения данных пользователей сотрудниками зала:
  - Информация об оплате и статусе подписки
  - Номер телефона
  - Адрес электронной почты (email)

## 3. Telegram-бот (Интеграция и уведомления)

- [ ] **Свободные рассылки** — разработать конструктор рассылок в панели управления для отправки произвольных сообщений (новостей, акций) по базе пользователей бота.
- [ ] **Автоматические поздравления** — настроить регулярный cron-таск для автоматической отправки поздравлений с днем рождения пользователям в Telegram.
- [ ] **Фильтрация пользователей по группам** — реализовать механизм группировки и фильтрации клиентов внутри бота для таргетированных рассылок и уведомлений.
- [ ] **Мобильный Check-In на ресепшн** — реализовать возможность быстрой регистрации визита (Check-in) пользователем через Telegram при нахождении рядом со стойкой ресепшн (геолокация или сканирование статического QR-кода клуба).
- [x] **Информация о подписке** — добавить в меню бота команду / кнопку для просмотра текущей информации о подписке (статус, оставшиеся посещения, дата окончания, статус заморозки).
